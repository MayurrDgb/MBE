# MBE-Presentations

Hub de présentations MBE (Produits / Services / Institutionnel), charté **MBE uniquement**, en **français**.
Destiné à un GitHub Pages dédié, indépendant du repo `Presentations`.

## Structure
- `index.html` — hub d'accueil (cartes par catégorie)
- `<Produit>/index.html` — un deck autonome par présentation

## Base technique
Stage 1200×675 scalé au viewport, moteur de slides, barre de navigation, persistance localStorage.
Charte MBE : police Ubuntu, blanc dominant, encre `#221E1F`, gris `#939598`, rouge `#E2001A` (accents, parcimonie).
